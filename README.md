# design/roadmap

A research-backed, explain-like-I'm-10 field guide to **graphic design from absolute zero**, built as a hand-crafted static website (plain HTML, CSS and a little JS, with no frameworks and no build step).

## Chapters

| # | Chapter | What's inside |
|---|---------|---------------|
| 00 | [Start](index.html) | What design is, why it matters, how to use the guide |
| 01 | [Taste & seeing](01-taste.html) | What taste is, the five-step taste workout, design movements, spotting generic design |
| 02 | [Design psychology](02-psychology.html) | Pre-attention, Gestalt, F/Z scanning, Hick/Fitts/von Restorff and other laws, first-impression research |
| 03 | [Colour](03-color.html) | HSL, harmony machine, colour psychology (with myth checks), how brands choose colour, 60-30-10, contrast checker |
| 04 | [Typography](04-typography.html) | Anatomy, type families, font psychology research, readability lab, type-scale generator, pairing |
| 05 | [Layout](05-layout.html) | C.R.A.P., hierarchy toggle and squint test, grids, composition, whitespace |
| 06 | [Market research](06-market-research.html) | How people decide, Kano model, research methods, brand-personality sliders, brief template, job market data |
| 07 | [Roadmap](07-roadmap.html) | 12-month plan with a progress tracker saved in your browser, books, tools and a glossary |

## Run it

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 5173
```
